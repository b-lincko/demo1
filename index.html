Sample Control: AC.L2-3.1.1

Limit system access to authorized users

Moderate Active Directory

Description

Only people who should have access can log in to your systems.

Why It Matters

If anyone can log in, hackers can access your data.

What to Implement

  • Create a list of authorized users
  • Create user accounts for each authorized person
  • Set strong passwords
  • Remove inactive accounts
  • Document everything

Estimated Time

2-4 hours initial setup

General Best Practices

  • Document Everything

    Keep detailed records of all security policies, procedures, and implementations.

  • Regular Training

    Conduct security awareness training for all employees at least annually.

  • Least Privilege

    Grant users only the minimum access necessary to perform their job functions.

  • Regular Audits

    Perform quarterly audits of user accounts, access rights, and security configurations.

  • Incident Response Plan

    Maintain an up-to-date incident response plan and test it regularly.

  • Backup Strategy

    Implement the 3-2-1 backup rule: 3 copies, 2 different media, 1 offsite.

Common Mistakes to Avoid

  • Shared Accounts

    Never use shared or generic accounts. Each user must have their own unique account.

  • Weak Passwords

    Avoid simple passwords. Enforce complexity requirements and regular changes.

  • Orphaned Accounts

    Failing to disable accounts when employees leave creates security vulnerabilities.

  • Unpatched Systems

    Neglecting to apply security updates leaves systems vulnerable to known exploits.

  • No Multi-Factor Authentication

    Relying solely on passwords is insufficient. Enable MFA wherever possible.
